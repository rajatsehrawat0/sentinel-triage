# Security and disclosure

No secrets, real customer records or family biometric data belong in this repository. Use synthetic fixtures. Never commit credentials, model caches or private enrollment datasets. If a secret is exposed, revoke it; deleting the file is insufficient.

The demos are local CLI prototypes, not hardened network services. No live financial transactions or external bookings are performed. Add authentication, input limits, persistence controls and deployment review before operating any service.

A private vulnerability-reporting contact must be configured after the GitHub account is confirmed. Do not post private data in public issues.
